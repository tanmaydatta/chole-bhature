# P0-3 · packages/engine port

## Context
Phase 0 ticket (M0 · Client Demo) — the single-engineer, promo-only slice. Spec §3 states `packages/engine` is lifted from `demo/src/lib` and is **100% reused by Phase 1** — Phase 0 completes it outright. This is the pure evaluation logic every endpoint (P0-5/P0-6) and the dashboard (P0-7) share. Depends on P0-1's monorepo scaffold.

## Scope
- Lift the demo's pure logic from `demo/src/lib` into `packages/engine`: `conditions` (the evaluator), `interpolate` (`renderMessage`), `rewards` (`rewardSummaryFor`), and `types`.
- Add zod schemas for the promo program/config shape.
- No React — the package is framework-free.
- Consumed by both `apps/api` and `apps/dashboard` (no duplicated logic).

## Acceptance criteria
- [ ] The engine package builds standalone with `tsc -b`.
- [ ] The demo's lib tests are carried over into the package and are green.
- [ ] The zod schema validates a well-formed promo config and rejects a malformed one.
- [ ] Both `apps/api` and `apps/dashboard` import from `packages/engine` — no logic duplicated between them.

## Technical notes
- Port only — no behavior changes to the demo's `conditions` / `interpolate` / `rewards` logic.
- The zod schema is the single source of truth for the promo config JSON shape stored in `programs.config` (P0-2); D1 does not validate it.
- Promo is the only consumer of the reward kinds in Phase 0; the type surface is complete for Phase 1's other program types to build on without changing the engine.

## Interfaces
**Consumes:** P0-1's `packages/engine` stub + monorepo layout.
**Produces:** the engine package — evaluator, `renderMessage`, `rewardSummaryFor`, shared types, and zod schemas — consumed by P0-5 (config validation), P0-6 (evaluate + message interpolation), and P0-7 (dashboard types/condition builder).
This **IS** Phase 1 **BE-3**, completed here — Phase 1 adds nothing to the engine beyond wiring the other program types' configs through the same schema surface.

## Out of scope
- Nothing beyond the port; promo is the only consumer of the reward kinds in Phase 0.
